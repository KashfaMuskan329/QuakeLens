THE METHOD BEHIND THE MAP

About QuakeLens

QuakeLens visualizes public USGS earthquake observations. Each dot reflects a published event with its reported magnitude, location, timestamp and depth. Data may be revised by USGS.

City Lens calculates straight-line great-circle distances between the chosen city center and reported epicenters. It does not model intensity, shaking, vulnerability, seismic hazard or forecast earthquakes.

Live feed loads USGS 30-day magnitude 2.5+ data, or an AWS Lambda/S3 cached equivalent if configured. When unavailable, the app explicitly labels its bundled USGS reference snapshot.

Built with Amazon Location Service (configured deployments), MapLibre GL JS, AWS Lambda, Amazon S3, EventBridge and API Gateway. Read USGS source details ↗
